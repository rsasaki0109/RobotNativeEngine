# H3 v1: 動的な箱の積み上げ

2026-10-30。正則化ゼロでも、**反復上限20は高質量比の積み上げに不足する**。
24条件中20条件が品質ゲートを通過。反復上限200は12/12条件が通過したが、
上限20は8/12条件で、上段10 kgの4条件すべてが失敗した。
単一箱でのH2成功を積み上げ一般に外挿できないことを実測で確認した。
ソルバー本体と既存H1/H2評価器は変更していない。

## 固定条件と独立した計測

一辺0.1 mの立方体を2段または3段に配置する。床と最下段、各箱の間に
5 mmの空隙を設け、初速ゼロから2秒間落下させる。重力は `(0,-9.81,0)`、
摩擦・反発係数ゼロ、全箱初期姿勢は単位回転。
上段だけ0.1 / 1 / 10 kg、その他は1 kg。慣性は `m × 0.1² / 6`。
刻み1 / 2 ms、反復上限20 / 200、正則化0の全直積24条件。

- 床へのめり込み: 毎ステップの全箱・全8頂点の最小高さ。
- 箱同士のめり込み: 全箱ペアに15軸のOBB分離軸法を適用。
  姿勢を無視したAABBや接触マニフォールドの距離を代用しない。
  平行辺の退化軸は除き、交差するOBBの最小平行移動深さを測る。
- 荷重伝達: 各箱の直下との法線力積を個別記録。
  最後の0.5秒の積分が、その接触面より上の総質量 × g × 0.5秒に一致するか確認。
  最下段は床との力積。エンティティ対の順序は問わない。
- 静止: 最後の0.5秒の並進・角速度。最終重心高さも各段の理想高さと照合。
- エネルギー: 全箱の位置エネルギー、並進・回転運動エネルギーの合計。

ゲートは床・箱間の最大めり込みそれぞれ10 µm、静止並進速度1 mm/s、
角速度0.01 rad/s、初期エネルギーからの超過率10⁻⁶、支持力積誤差1%、
最終高さ誤差0.1 mm、法線力積非負。実行前に固定した。
幾何計測はステップ終了時のみで、連続非貫通の保証ではない。

## 結果

| 設定 | 合格 | 観測 |
|---|---:|---|
| 正則化0・上限20 | 8/12 | 上段10 kgの全4条件が失敗 |
| 正則化0・上限200 | 12/12 | 全質量比・段数・刻みでゲート通過 |

最も厳しい失敗は3段・上段10 kg・2 ms・上限20。
最大床めり込み **569.6 µm**、箱間 **465.0 µm**、積み上げも崩れた。
同じケースを上限200で実行すると、床 **0.0651 µm**、箱間 **0.0385 µm**、
静止並進速度 **0.0314 mm/s**で通過した。1 msへ刻みを縮めるだけでは、
上限20の高質量比ケースを救えなかった。

上限200・2 msでの計算費用中央値は、物理1秒あたり **12.48–43.61 ms**。
上限200は毎回必ず200回反復するという意味ではなく、既存の早期収束判定も使う。
コストは同一論理CPUに固定し、新しいワールドでウォームアップ1回・計測5回。
release backendのステップループだけを計測し、起動・モデル生成・ECS同期・
トレース・JSONを除外する。失敗して崩れたケースの安い費用を性能改善と数えない。
MuJoCoの積み上げ比較は未実施であり、速度倍率は主張しない。

## 再現とCI

```bash
cargo build --locked --release -p rne_physics_native --example stack_drop
RNE_STACK_DROP=target/release/examples/stack_drop python -m unittest discover -s scripts/contact_benchmark -v
python scripts/contact_benchmark/stack.py target/release/examples/stack_drop /tmp/stack.json.xz
python scripts/contact_benchmark/stack.py target/release/examples/stack_drop /tmp/stack.json.xz --verify
```

各条件の全姿勢・速度・力積トレースは2回実行して完全一致。
監査実行と全計測実行の最終姿勢・両速度も一致を要求する。
`--verify` は保存データから24条件の品質と費用中央値を再計算し、
グリッドの欠落・重複、評価器ハッシュ、最終状態を検証する。
**検証器の成功は全条件の品質合格を意味しない**。既知の失敗4条件も保存する。
CIの統合テストは上限200の固定参照12条件すべての品質合格を要求し、
探索全24条件の生データはActions artifactに残す。

[集計とハッシュ](evidence/stack-contact/h3-v1-summary.json)をGitに保存。
生データ `stack-h3-v1.json.xz` は6,444,352 bytesのためADR034に従って別成果物とし、
Gitには入れない。今回のローカル実測の恒久公開URLは未取得。
CIで新たに採ったデータと今回のローカル記録は別物である。
速度はECSの姿勢差分、力積イベントはf32精度という制約はH2と同じ。

## 次の開発対象

高質量比で反復不足となる接触島を測り、収束品質を保ったまま計算費用を下げる。
この失敗ケースを固定して、ソルバーの収束残差・反復回数の計測と改善を進める。
その後、MuJoCoを含む同品質の費用比較を行う。
今回の軸整列・摩擦なし・最大3段以外の任意姿勢、摩擦、長時間安定性、
衝撃の位相依存性、より大きな質量比や段数は今後の検証対象。
