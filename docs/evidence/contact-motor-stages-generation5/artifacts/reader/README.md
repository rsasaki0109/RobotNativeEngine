# New prospective generation-five reader

No authoritative worlds have been collected by this work. This directory owns a
new all-motor admission rule for a new cohort; prior generation-four reader,
palm-only gate, failed outcome and raw evidence are immutable. The numerical
module and checkpoint/framing module retain their historical source bytes.
Source references are selected proof, not a complete compiler/dependency closure.
The actual Rust collector and vendor solver remain unchanged.

The runtime reader closure consists of `audit_coupled_stages.py`,
`stage_analysis.py`, `stage_numeric.py`, `stage_schema.py`, `stage_roles.py` and
`synthetic-profile.json`. That profile contains the original literal resource
ceilings and independently rederived source parameter words. The synthetic tests
use separately marked operands/metadata and execute no native program, build,
old numerical reader, old measurement read or physics world.

`protocol-template.json` and `source-binary-binding-template.json` are unexecuted
templates. Root creates distinct frozen artifacts after reader/source review and
supplies actual protocol/driver/source/binary/compiler/feature/float-model
bindings. The cohort is `generation5-independent-all-motor-stage`; no fresh scalar
worlds are part of its eighteen-cell collection. The driver spec additionally
includes `registered_utc` for a pre-world freeze check. Its schema2 collection
index and all original Popen exit/case/launch receipts are independently checked.
No post-collection repair fields exist in this reader.

The prospective invocation after actual collection is:

```text
python3 -B reader/audit_coupled_stages.py \
  --protocol ABSOLUTE_FROZEN_PROTOCOL --protocol-sha256 LITERAL_SHA \
  --collection ABSOLUTE_COHORT_ROOT/collection-index.json --collection-sha256 LITERAL_SHA \
  --output EXCLUSIVE_NEW_JSON_RESULT --details-directory EXCLUSIVE_NEW_DIRECTORY
```

The reader streams all eighteen original gzips in six fixed ON/fresh-ON/OFF
triples, retains all finite/reference/native exclusion counts and compressed
per-interval details, and never launches a world or writes an input. Complete
qualification requires all three source-derived native roles: palm ForceBased,
finger slots AccelerationBased with zero authority. Actual root/compiler/source
binding and all comparisons must qualify before any measured claim. Unknown
metadata, incomplete framing or changed source remains a retained FAIL; any
native-domain exclusions remain incomplete/unqualified. Finger slot names mean
link order, not an independent anatomical left/right frame decode. Absolute RHS
origin and private/per-contact structures remain unmeasured.

Exit 0 means the registered scoped arithmetic/replay checks passed. Exit 1 means
the actual result is failed or incomplete and remains retained, with no retry,
retuning, post-outcome schema change or candidate promotion. The separately
registered SHA-only historical archive recovery arm has no influence on this
numerical qualification.

Pure qualification command:

```text
python3 -B -m unittest -v test_stage_numeric test_stage_reader test_stage_provenance
```

Run receipts, including the first two synthetic harness failures, are retained
under `pure-tests-attempt-*`; their world/build/native-data counts are zero.
