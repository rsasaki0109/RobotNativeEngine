# Sequential driver and source/binary binding contract (pre-data)

The neighboring templates are PREPARATION, not an actual source/binary freeze.
Root fills actual paths/hashes/byte lengths and timestamps before the first
authoritative world. Reader/tool/schema/protocol criteria and both source/binary
variants are frozen before any world. Compile baseline142+141, compile the exact
runtime-only rejected candidate142, restore baseline sources, then bind all of
these artifacts before collection. Both bindings must precede the index's actual
start timestamp. No candidate source needs to remain checked out while its frozen
binary is executed; the literal patch reconstruction binds that historical variant.

The reader CLI will be:

    python3 -B audit_coupled_stages.py \
      --protocol ABSOLUTE_PROTOCOL_JSON --protocol-sha256 LITERAL_SHA256 \
      --collection ABSOLUTE_COLLECTION_INDEX_JSON --collection-sha256 LITERAL_SHA256 \
      --output ABSOLUTE_NEW_OUTPUT_JSON --details-directory ABSOLUTE_NEW_DIRECTORY

It creates no world/build. It never overwrites outputs or changes input artifacts.
Every artifact record is exactly {path,sha256,bytes}; absolute paths and actual
lowercase SHA256 are required. A prepared placeholder is not admitted.

The index has precisely the eighteen ordered cells in collection-index-template.
The driver constructs no additional scene and invokes exactly one fixture process
per attempted entry, with the bound binary and --mass-kg, --observer, --label,
--output flags. Keep all pending/unattempted/partial/failed entries and errors in
the index if collection stops. Do not replace an existing compressed output.
Terminal complete status is ACTUAL_COUPLED_18_WORLD_COLLECTION_COMPLETE, with
worlds_attempted=worlds_completed=18, every exit0, every error=null, and actual
source guards before/after every process. The reader preserves an audit failure
when a collection is partial; a partial index never becomes successful coverage.

Use modes on/fresh_on/off, with on/fresh_on passing --observer on and off passing
--observer off. Labels are the exact template labels (build-mMASS-mode). A hyphen
or underscore within a label has no physical significance, but the declared label
must match the actual header and argv; do not choose labels from outcomes.

Both source bindings name the same merged base c515029a..., actual compiler,
features, flags, schema sources and observer implementation. Baseline is the
restored production diagonal; rejected_inverse_w_plus_g changes only the exact
previously rejected ForceBased unit-row reciprocal expression. Its patch must be
registered before baseline worlds and remains rejected under the existing gate.
Source manifests/guards bind all runtime/collector/fixture/dependency inputs, not
only the scalar example's selected report map. Each build must have zero worlds
of that build before its actual freeze. Compare timestamps against its first
collection process. Stored source maps and per-process guards allow historical
candidate verification without requiring both source variants simultaneously in
the checkout. Any unexpected delta fails; later rollback is separately bound.

The float-mode object binds actual target/features and the source FTZ/DAZ predicate,
compiler flags and strict separate-operation/RN contract. Its scope explicitly
states that runtime registers are unmeasured unless a separate actual register
receipt exists. Do not fabricate a runtime MXCSR measurement. Native replay
coverage is restricted to normal/zero arithmetic and its literal selected-visit
word comparisons are the empirical check; reference metrics remain independent.
