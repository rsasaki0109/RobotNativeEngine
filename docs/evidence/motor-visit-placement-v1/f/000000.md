## Hypotheses are conditional, not required differences

For identical initial fixture/constructor inputs, profile counts do not enter
motor coefficients or h=outer_dt/N. Therefore require the source-identified first
row's matching actual gains/h/targets/ERP/RHS/g/D/J/W/bounds and incoming V across
profiles, aside from explicitly differing configuration metadata. If this gate
fails, cross-profile attribution is FAILED/UNQUALIFIED.

- Baseline and PGS1/S0 have the same first preintegration visit. First-slice
  integration q/V should match under admitted native arithmetic; additional
  baseline visits may change final generic V afterward.
- Baseline and PGS3/S0 have the same total count, but integration occurs after
  one versus three visits. Given the same fixed-cache deterministic visit map,
  equality of the first-slice final V can coexist with unequal q. Test the actual
  preceding integration V, not a substituted final/writeback V.
- Clamping, an already projected fixed point or an odd-cycle map can make the
  first and third visits equal. Do **not** require unequal q or final V. Matching
  profiles can be a scientifically INCONCLUSIVE discriminator despite passing
  fidelity/coverage. Later slices can have different incoming states; do not
  extrapolate first-slice equality unconditionally through all 32 slices.

No outcome selects a better profile or changes old calibration. A missing
observation, source-replay/projection mismatch, cache/identity failure or observer
neutrality failure is FAILED/UNQUALIFIED, not an inconclusive physical result.

## Three separate comparisons

1. **Recorded native fidelity:** existing source-ordered f32 operations, strict
   words/identity/cache/coverage and projected bounds. Freeze normal/zero-domain
   eligibility and explicit nonfinite/subnormal/tiny/overflow treatment before
   data. Runtime MXCSR/rounding/FTZ/DAZ remains unmeasured.
2. **Conditional row algebra:** exact-real `w`, g, RHS and actual incoming V imply
   the capped fixed point and visit recurrence. Inferred I_effective=1/w is a
   row-algebra quantity, not independent physical inertia validation.
3. **Independent SI reference:** declared sphere I=2mR²/5, stationary target and
   capped backward Euler. Retain both the reference trajectory advanced from its
   own previous q/V and clearly labeled one-step counterfactuals using native
   incoming q/V. Never mix the two or silently replace physical I by 1/w.

The supplied Fraction helper computes only comparisons 2/3 in ideal real
arithmetic. Its 10 synthetic tests are not native f32 replay. SI mismatch is a
separate diagnostic, not reclassification of the prior four primary cases or
their unchanged accuracy thresholds. No physical improvement/causal conclusion
is predetermined. No normalization intervention or gain search is included.

## Required freeze fields

Bind the cohort ID and all 18 case argv/order/output claims; collector and all
reader/helper sources with exact bytes/hashes; unchanged native source manifest
with scope caveats; actual Cargo.lock/compiler/target/features/flags/native-float
model and binary; exact CLI/profile framing and parameter metadata; observation
schemas/capture-site schedule; pure tests and independent pre-data admission.
State checkpoint exclusions explicitly: full sets, private pipeline/solver/
contact caches and observer buffers. Source-bound native postcard roundtrip does
not prove an independent decoder or universal hidden-state equality.

Within each profile/sign require captured initial/final ON/fresh/OFF equality
and ordered complete ON/fresh telemetry equality; OFF all three null. Cross-profile
state equality is not required because configuration differs. Preserve all
outer/child/reader original exits and whole/partial/error records, validate fixed
budget and unchanged sources before/after each process, and perform only the
registered reader execution. Physics correction and production adoption remain
separate tasks subject to the unchanged examples133–138 regression gate.
