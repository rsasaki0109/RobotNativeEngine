## Scalar real-arithmetic convention

For an admitted stationary-target, isolated one-DOF motor, let h > 0, generalized inertia M > 0, w = 1/M, S = h*kp+kd > 0, a = kp/S, g = 1/(h*S), and b = v_free + a*(q_old-q_target). Revolute units are q [rad], V [rad/s], M [kg m²], kp [N m/rad], kd [N m s/rad], applied impulse p [N m s]; native lambda = -p. The conventional implicit-PD pair obeys q_new = q_old+h*V_new, V_new = v_free+w*p and p = h*(kp*(q_target-q_new)-kd*V_new). Its real fixed point is p = -b/(w+g), projected to the effort impulse interval.

The actual internal row uses D = inv(w), not inv(w+g), and each solve evaluates JV, rhs+JV, then lambda + D*(rhs+JV-g*lambda), clamps it and applies V.axpy(-delta_lambda,W,1). See `motor_model.rs:32-35`, `unit_multibody_joint.rs:119-156`, `joint_generic_constraint.rs:519-534`. In isolated uncapped real arithmetic the error factor is -g/w. This describes finite-iteration behavior; it does not establish observed convergence or qualify the rejected diagonal change. Native ERP, inverse guards, bounds, dot/axpy and integration rounding must be audited in their source order, not replaced by a rearranged double-precision expression. q uses multiply then add at `multibody_joint.rs:108`.
