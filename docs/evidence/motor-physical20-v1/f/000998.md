## Fixed source contract

`schema-source-contract.json` enumerates the exact twenty case IDs, order and
input IEEE words from the root protocol-source-template. There are sixteen
nonzero cases: mass{0.5,2}kg × h{0.0005,0.002}s × target{−0.001,+0.001}rad ×
ceiling{2,0.01}Nm. Four zero-target controls use each mass/h pair with ceiling2.
All cases retain radius0.1m, kp300Nm/rad, kd12Nm s/rad, one outer interval,
N1/PGS1/stabilization2, fixed coincident identity X-revolute frames, zero initial
q/V/targetV/gravity/body and passive damping/armature. Sleeping/CCD/limits/joint
contacts are disabled; only the dynamic sphere has a collider. Runtime source
checks retain one DoF, two links, two bodies and one collider.

The exact five mandatory flags are:

```text
--case CASE_ID --variant baseline|candidate --observer on|off
--label LABEL --output ABSOLUTE_NEW_FILE.jsonl.gz
```

`variant` is literal metadata only. It NEVER selects the equation, fixture or
observer setting at runtime. The frozen binary and root build/config bindings
establish its actual identity. Fresh ON uses observer `on` and label `fresh_on`;
other labels are `on`/`off` in the fixed driver. The parser permits 1–64 ASCII
letters/digits/underscores/hyphens, and rejects unknown/repeated/missing flags,
undeclared cases and tuning. Help/malformed input constructs no fixture.

The NEW header study_kind is `rne_isolated_forcebased_physical_motor_v1`.
RunStart adds study_kind/case_id/variant; its declarations include every actual
input word and fixed counts. All checkpoint, body/inertia, native-byte,
companion-v1, stage-v1 and promoted impulse-word projections retain example143's
literal struct/helper source. Coordinate integration input and final writeback
remain distinct phases. Descriptor motor.impulse is not a measured internal row
impulse; internal MAX writeback behavior remains unchanged.

Framing is run_start, initial_state, completed_interval ordinal1, run_end.
The gzip is claimed exclusively; a durable header precedes Fixture construction.
Every record is flushed/fsynced. Errors/panics preserve earlier records and attempt
a failed terminal. A step panic preserves the original panic while attempting
partial checkpoint/available telemetry; partial writing and finalization errors
remain explicit. Completed collection exit0 establishes no physical accuracy.
OFF observations must be null, not fabricated zeros. State scope is sorted
individual source-bound objects/public words/parameters; full-set metadata,
broad/narrow phase, private solver/contact caches and observer buffers are excluded.
