# Separately registered 72-world source-transition driver

The tool and tests are outside the checkout. The old draft/handoff is unchanged.
The source transition remains independent of G5 fixed18 and example-143 six
construction worlds. No real report is decoded by preparation or freezing.

141 accepts **`--output FILE`**, not `--write-report`. Its `collect_report()`
loops over the existing 24 cells and calls `run_once(true), run_once(true),
run_once(false)` inside each cell. The driver launches **one** collector process
for its 72 internal attempts, not 72 subprocesses. It explicitly adds
`--require-calibration` and retains expected original exit **2**. A complete
unchanged FAIL 0/4 is the required retained result, not a scientific PASS.

## Final tool evidence

Driver/stub tests live in test_driver.py. Actual tests run with run_tests.py into
a new exclusive attempt directory. They only create labeled synthetic fixtures
and run a Python stub. They exercise full collection + three zero-world gates,
partial exit/output preservation, retry refusal, byte tampering, strict types,
source/descriptor changes, stale review, explicit environment, launch failure,
and PID-receipt storage failure preserving an already launched child's exit.
Each receipt binds driver, comparator, test source and runner SHA. Old attempts
and synthetic fixtures are retained, not cleaned up.

## Required input format

Create a persistent supplied-inputs.json with precisely these top-level fields:

```json
{
  "kind": "rne_141_source_transition_inputs",
  "schema_version": 1,
  "run_root": "/workspace/<new-exclusive-once-only-arm-root>",
  "source_root": "/workspace/RobotNativeEngine",
  "environment": {"LC_ALL": "C", "LANG": "C"},
  "transition": {
    "kind": "rne_141_motor_construction_source_transition",
    "schema_version": 1,
    "status": "FROZEN_BEFORE_COLLECTION",
    "baseline_report_sha256": "<original full DB0 file SHA>",
    "before_source_sha256": {"<all exact 21 paths>": "<actual frozen SHA>"},
    "after_source_sha256": {"<all exact 22 paths>": "<actual frozen SHA>"},
    "changed_existing_paths": ["<exact sorted actual changed paths>"],
    "added_paths": ["third_party/rapier3d/src/pipeline/multibody_motor_construction.rs"],
    "removed_paths": []
  },
  "artifacts": {"<role>": {"path": "/workspace/<file>", "sha256": "<hex64>", "size_bytes": 123}}
}
```

The supplied maps come from the parent's final actual
selected-source-transition-maps.json: `before`→before_source_sha256,
`after`→after_source_sha256, and its literal added/changed/removed arrays. The
final integrated mapping has 11 existing changes and one addition; the tool
rejects any undeclared difference. Source after-map must equal actual guarded
file bytes. No map is guessed from numerical output or rewritten into DB0.

The environment is the complete literal child environment. No ambient variables
are inherited by the binary. Parent chooses/binds this before review; the shown
locale-only map is a proposal. The source/compiler/build receipt separately
retains actual build selectors, feature tree, toolchain and target. Do not put
credentials into the child's environment.

Required artifact roles:

- binary: the parent's pinned workspace copy of 141, SHA 9ff1b9d0… (3,144,136 B
  for the supplied current build; actual descriptor must verify).
- build_receipt: the normalized binding below, with the original actual build
  binding/receipt/log/source-guard/feature/toolchain descriptors retained under
  additional artifact roles. Normalizing metadata does not create a new build.
- source_guard: this driver's full source-guard output. It guards tracked and
  nonignored Rust/Cargo/config plus all vendor .rs/.toml/lock inputs, explicitly
  non-exhaustive compiler closure. Retain the parent's original build guard as
  an additional artifact; its entries must reproduce current bytes before freeze.
- protocol: exact `driver.fixed_protocol()` JSON, independently reviewed before
  data. It binds fixed order, single collector/72 budget, require exit2, no retry,
  source-only allowance and three subsequent zero-world checks.
- baseline_report: original contact-stages DB0 descriptor, streamed SHA/size
  only during preparation. Never decode or overwrite it in pre-data tooling.
- baseline_source_map_receipt: the exact provenance binding below, supplied and
  independently reviewed by the parent; the tool does not infer it by numerical
  baseline analysis.
- driver_source: this exact driver.py; comparator_source: the unchanged parent
  compare_scalar_source_transition.py; test_source: this test_driver.py;
  test_runner_source: this run_tests.py.
- pure_test_receipt and pure_test_log: final actual PASS terminal.json and
  command.log with matching tool hashes. Include the prior comparator test
  receipt/source/log as additional roles when freezing the complete tool closure.

Every descriptor is a canonical absolute regular, nonsymlinked file under

Add other source/compiler/features/environment/protocol/reader/review references
as additional artifact roles; every supplied role is revalidated during the arm.

## Preparation, review, freeze and one explicit run

All commands below are prospective. This agent has run synthetic tests only.
Use unique persistent directories and do not overwrite an existing artifact.

```text
python3 -B driver.py source-guard --source-root /workspace/RobotNativeEngine --output <new-source-guard.json>
```

Write the protocol from fixed_protocol() exclusively and create the supplied
input descriptors and normalized receipt. Then:

```text
python3 -B driver.py prepare --inputs <supplied-inputs.json> --out-dir <new-prepared-directory>
```

This validates exact tools/maps/binary/environment/build/source bindings, writes
prepared-bindings.json and a preparation terminal with zero worlds, and requires
independent review. The review file must contain these exact acceptance values
(extra review detail/ledgers are allowed):

```json
{
  "kind": "rne_141_independent_precollection_review",
  "status": "PASS_INDEPENDENT_PRE_COLLECTION_SOURCE_TRANSITION_REVIEW",
  "before_world_collection": true,
  "reviewed_prepared_binding_sha256": "<actual prepared SHA>",
  "reviewed_prepared_binding_size_bytes": 123,
  "world_budget": 72
}
```

The reviewer must check real provenance/closure/once-only semantics; a status
string is not sufficient evidence. Write its actual descriptor to a separate
review-descriptor.json. Freeze with:

```text
python3 -B driver.py freeze --prepared <prepared-bindings.json> --review-descriptor <review-descriptor.json> --out-dir <new-freeze-directory>
```

Freeze produces frozen-bindings.json and terminal.json with its actual full SHA.
Root independently retains that expected SHA. Only then execute once:

```text
python3 -B driver.py run --frozen <frozen-bindings.json> --expected-frozen-sha256 <independently retained full SHA>
```

The run first revalidates the independently retained freeze SHA and artifacts.
Its exclusive run-root directory plus claim.json consumes the one attempt.
Collection is binary --output new-report.json --require-calibration. The report
is **not precreated** by the driver: 141 must create it exclusively before any
world. Logs, PID/start/terminal receipts, partial report and original exit are
preserved. A launched child is waited once even if PID-receipt storage fails.
A crash/hard storage failure may leave incomplete receipts and a consumed claim;
this cannot authorize a rerun.

Only a complete exit2/FAIL0/4/72 counters with unchanged guards proceeds to the
literal source-object-only comparator. Then exactly three zero-world processes
run: current loaded verify (0), current loaded require verify (2), old loaded
stale-source rejection (1). All original exits/logs persist. No old output or
raw data is replaced; any failure stops remaining gates and retains the claim.
Admission status describes source equivalence, not calibrated accuracy.

Broad guards apply at preparation/freeze and during this one collection/gate
attempt. After its terminal, xtask/docs may change to point at the new report.
Do not retroactively require the entire old broad guard to equal a later tree.
The original before/after snapshots remain historical literal receipts; future
zero-world CI verification uses 141's current selected map. The driver is not
a historical requalification command, and a completed arm cannot be rerun.

Only after admission may the complete aggregate current scalar report be copied
to docs/media/position-motor-calibration-motor-construction-source.json. Raw
traces/large provenance stay under ADR034 retention rules; output is
PROPOSED_NOT_PUBLISHED until the parent's publication work and any required
authorization/retrieval proof are actually complete.
