`compare_scalar_source_transition.py` is a pure bytes-in/bytes-out library. The
synthetic tests construct all input report bytes locally and never access real
reports or source payloads. The caller must authenticate the frozen protocol,
tool closure and binary/source guard before supplying real report bytes.

The comparator validates full before/after maps with exactly 21 and 22 keys,
lowercase full SHA-256 values, no removals, only the one declared addition,
and an exact sorted list of existing changed keys. The baseline must match its
frozen full-file SHA. Duplicate JSON keys and non-JSON numeric constants fail.

not count. Only that object is replaced using the collector's unchanged sorted,
two-space pretty encoding. The complete resulting byte stream must equal the
collected report. Every protocol, case, order, signed zero, native word/postcard
byte, telemetry field, sensitivity record, summary, and trailing byte outside
the object remains literal. No numerical recomputation or tolerance is applied.

This is deliberately separate from the unchanged collector's full verifier.

then use the normal current-source loaded verifier. Do not run a historical
reader against old data to reinterpret scientific findings. Failed byte equality
rejects the new source-transition admission; it cannot be waived because a new
