## Interpretation and reproduction limits

The unchanged contact-free sphere fixture has radius 0.1 m, mass 1 kg, identity
fixed-parent X-revolute frames, ForceBased gains 300 Nm/rad and 12 Nm s/rad,
a 2 Nm ceiling and targets −0.001/+0.001 rad. Gravity, passive damping, armature
and initial V are zero. Each fresh process runs one 1 ms interval with 32 small
steps, one PGS pass and two stabilization passes. No solver intervention or
parameter search was included.

The companion records actual construction inputs and distinct integration,
stabilization and final-writeback endpoints. The coordinate check uses the
captured preceding integration velocity, not a later stabilized/final velocity.
IEEE words and individual-object native postcard bytes define the captured state;
source-bound decode/reencode is not an independent private-layout decoder.
Full-set metadata, private pipeline/solver/contact caches and observer buffers are
excluded. Runtime MXCSR/rounding/FTZ/DAZ was not measured; arithmetic checks remain
limited to the declared source/compiler and float-domain model.

Source reconstruction uses Git base `3be26ef0bd6967cf3e0b466a5b63b11795f40feb`
plus mapped physics/collector snapshots, locks and build descriptors. The archived
RNE_PATCH.md is the preparation-era document; the main documentation was updated
separately after export. These records bind the measured build, not every later
publication-document byte. The build record is nonhermetic and does not guarantee
a cross-machine bit-identical rebuild. Historical scripts keep their original
paths and are not portable current-checkout verifiers. Native executables are
not distributed in this bundle.

These diagnostic consistency results establish no calibration improvement,
coupled-contact cause, hardware validation, candidate adoption or maturity gain.
