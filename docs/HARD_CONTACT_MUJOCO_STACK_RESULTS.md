# MuJoCo積み上げ校正 v1

2026-10-30。MuJoCo 3.9.0を既存H3と同じ箱・重力・質量・幾何評価器で測定し、
今回の探索範囲では **0/24条件が全品質ゲートを通過**した。
最も小さい最大床めり込みでも61.96 µmで、基準10 µmを超えた。
この段階では同品質の速度倍率を出さない。MuJoCoの最良性能や達成不能を意味しない。

## 校正条件

一辺0.1 mの箱2/3段、上段質量1/10 kg、他は1 kg、各接触間隔5 mm。
摩擦・反発ゼロ、重力Y=-9.81、2秒。刻み2 / 1 / 0.25 msと
solref `(0.02,1)` / `(2e-6,10)` の全直積24条件。
Newton・Euler・反復上限200、許容差10⁻¹⁰、condim1、elliptic cone、
solimp `(0.999,0.999,0.001,0.5,2)`、margin/gap0。
refsafeは有効で、要求した2 µsの時定数は少なくとも刻みの2倍へ制限される。
この下限を含めた追加探索が次の段階になる。

全箱のfreejoint姿勢をxyzw順へ変換し、ローカル角速度を世界座標へ回す。
接触力積は各箱と直下の箱（最下段は床）のgeom対で集計する。
各ステップ終了時の姿勢から、既存H3の全頂点・OBB分離軸法で床と箱間の
めり込みを再計算する。MuJoCoの接触距離を幾何計測に代用しない。
既存の荷重伝達・回転を含むエネルギー・静止速度・最終高さのゲートも適用し、
警告または時刻リセットを別の失敗条件とする。

例として3段・上段10 kg・0.25 ms・solref `(2e-6,10)` は、床61.96 µm、
箱間87.56 µm。静止と荷重伝達が良好でも最大めり込みゲートが不合格になる。
既存H3のNativeは2 ms・正則化0で通過しているが、今回はMuJoCo校正のみで、
Nativeを同時再計測した速度比較や未観測条件での汎化評価はしていない。

## 再現と証拠

```bash
python scripts/contact_benchmark/mujoco_stack.py /tmp/mujoco-stack.json.xz
python scripts/contact_benchmark/verify_mujoco_stack.py /tmp/mujoco-stack.json.xz
```

既存MuJoCo用requirementsと同じPython環境を使用する。
全24条件で監査トレースの完全再実行一致、監査と5回の計測の最終状態一致を要求。
一つのCPUに固定し、ウォームアップ後の新規ワールドを5回計測する。
計測は `mj_step(nstep=...)` のバッチのみで、生成・Python監査・JSONを除く。
記録には完全なMJCF、設定、全姿勢・速度・接触面力積、警告、時間、費用を保存する。
検証器は保存データから24条件の存在、評価器ハッシュ、品質、最終状態、費用を再検証する。
校正の失敗は正常に保存するため、検証器成功は全品質合格を意味しない。

[集計](evidence/mujoco-stack/calibration-summary.json)に全指標と生データSHA-256を保存。
生データは別成果物 `mujoco-stack-calibration.json.xz` として提供し、ADR034に従って
Gitには追加しない。今回の記録の恒久公開URLは未取得。
CIも校正を実行し、新しく採った全トレースをartifactへ保存する。
26件のPythonテストが通過し、座標変換、質量・慣性・初期配置、支持力積の計測を確認した。
Rustソルバーの変更はない。全workspace検証は先行のディスク不足のため再実行していない。
