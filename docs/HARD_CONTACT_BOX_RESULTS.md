# H2 v1: 箱の落下と複数頂点接触

2026-10-30。Native backend の **48/48 条件**が今回の品質ゲートを通過した。
正則化ゼロの 24 条件で最大めり込みは **3.63 × 10⁻¹² m**、
正則化 0.001 の 24 条件では **5.41 µm**。
これは各ステップ終了時の全8頂点を実際の姿勢から計算した結果であり、
ステップ間の連続非貫通や一般形状の保証ではない。

## 固定した試験

- 一辺 0.1 m、質量 1 kg の立方体。重心は中心、等方慣性 `m a² / 6`。
- 床上面 Y=0、重力 `(0,-9.81,0)`、摩擦・反発係数ゼロ。
- 初期 Z 回転 0 / 0.1 / 0.4 rad。最下頂点の初期床間隔 0.1 / 0.5 m。
- 時間刻み 1 / 2 ms、反復上限 20 / 200、正則化 0 / 0.001。全直積48条件。
- 各2秒。姿勢・並進速度・角速度・法線力積を毎ステップ保存。
- 同一条件を2回実行して全トレース完全一致を確認。別途ウォームアップ1回、
  新しいワールドで計測5回。計測実行の最終姿勢・両速度も監査実行と完全一致。
- 一つの論理CPUに固定。時刻計測は release backend のステップループのみ。
  モデル生成・プロセス起動・JSON・ECS同期・トレース生成を含めない。

球の評価器は変更していない。箱には新たな H2 ゲートを事前に定義した。
最大めり込み10 µm、最後の0.5秒の最大並進速度1 mm/s・角速度0.01 rad/s、
初期位置エネルギーに対する全機械エネルギーの超過率10⁻⁶以下、
最後の0.5秒の合計法線力積と `mg × 0.5 s` の誤差1%以下、法線力積非負。
エネルギーには重心高さ、全並進速度、全角速度を含む。
床の接触マニフォールドの距離を幾何計測に使わない。

## 計算費用

正則化0・反復20・刻み2 msの6条件では、物理1秒あたりの計算時間中央値は
**3.83–4.73 ms**。同条件の球より接触点処理が増えるが、箱も大きい刻みで
上記ゲートを満たした。MuJoCo の箱試験はまだ実行しておらず、
H1の約342倍という結果を箱へ外挿しない。最速設定を選んだ汎化評価でもない。

## 再現と証拠

```bash
cargo build --locked --release -p rne_physics_native --example box_drop
RNE_BOX_DROP=target/release/examples/box_drop python -m unittest discover -s scripts/contact_benchmark -v
python scripts/contact_benchmark/box.py target/release/examples/box_drop /tmp/box-contact.json.xz
python scripts/contact_benchmark/verify_box.py /tmp/box-contact.json.xz --require-pass
```

Python環境は既存の contact benchmark と同じ NumPy 環境を使う。
[集計記録](evidence/box-contact/h2-v1-summary.json)に48条件の設定、品質指標、
5回の費用、バイナリと評価器のSHA-256を保存した。
生トレースは `box-contact-h2-v1.json.xz`（3,206,436 bytes）。集計記録に
そのSHA-256を記録し、今回の作業成果物として別途渡す。恒久公開URLは未取得。
ADR034の1 MiB上限に従い、生データはGitへ追加しない。
CIは新しく実行した集計と全トレースを `hard-contact-drop` artifact に保存する。
CIの記録と今回のローカル実測を混同しない。
検証器は全48条件の存在と重複、評価器ハッシュ、全トレースからの品質指標、
費用中央値、最終状態を検証する。計算時間そのものの再測定ではない。

## 限界と次の段階

今回は単一の摩擦なし立方体と固定床で、回転軸もZのみ。
静止に至るまでの複数頂点の接触は扱うが、動的物体同士の積み上げ、
摩擦、質量比、任意姿勢、連続した落下高さの位相探索は未検証。
速度はECSのステップ間姿勢差分で、力積イベントはf32精度。
H1の解析衝突力積や反発高さのゲートを傾斜箱にそのまま適用してはいない。
これは今回定義した品質指標での診断であり、全衝突応答の正しさの証明ではない。
