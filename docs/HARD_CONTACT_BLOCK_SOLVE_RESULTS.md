# 剛体・摩擦なし接触の一括法線解法

2026-10-30。H3で崩れていた高質量比の積み上げを改善した。
固定した24条件は変更前20/24合格から **24/24合格**になり、
両方式とも合格する反復上限200の12条件では、平均計算費用が
**30.149 → 24.143 ms／物理1秒（約19.9%減、1.249倍）**になった。
これはRNEの変更前後の比較であり、MuJoCoとの比較ではない。

## 変更

従来の逐次更新は、重い上段の荷重が接触を介して下段へ伝わるまで多くの
反復を必要とする。摩擦係数がすべて0、正則化0、緩和係数1、接触数2–32の
場合に限り、法線方向の相補性問題を小さな連立問題として先に解く。

1. 前ステップの力積を、現在の未変更のDelassus行列と自由速度で検証する。
   法線力積非負、開いた接触の法線速度非負、力積を持つ接触の法線速度ゼロを
   満たす場合だけ再利用する。許容差は既存の速度許容差（標準10⁻⁸ m/s）。
2. そうでなければ有効な接触集合を更新し、法線行列を行ピボット付きで消去する。
   重複した接触による特異性を許し、自由変数をゼロにする。
   対角への微小ばねや正則化は追加しない。
3. 負の力積を持つ接触を外し、閉じつつある非有効接触を加える。
   有効集合の試行は `min(max_iterations, 2n+1)` 回に制限する。
4. 全接触について元の式の相補性を検証できた解だけ採用する。
   不整合・循環・数値的不成功なら元のウォームスタートから従来のGSへ戻る。

フォールバック時のGS予算は変更しないため、有効集合試行の費用は追加になる。
32点上限は大きな問題での密行列分解の増大を制限するためであり、
大規模接触群や摩擦付き接触への性能改善は主張しない。
単一接触、正則化あり、摩擦ありは従来経路。Nativeの既定正則化0.001も変更しない。

`ContactSolution.normal_block_iterations` と `normal_block_solved` を追加した。
`iterations` は従来どおりGSの掃引数で、一括解法で解いた場合は0になる。
接触ステップの `solver_iterations` もGS掃引数なので、0は計算費用ゼロを意味しない。
決定的な順序で動作し、以前のバージョンとのビット一致は保証しない。

## 品質と費用

H3の形状・質量・初期条件・評価器・ゲートは変更していない。
反復上限20/200の全24条件で、床・箱間のめり込み、静止速度、荷重伝達、
エネルギー、最終高さの各ゲートを通過した。
3段・上段10 kg・2 msでの最大箱間めり込みは約 **6.27×10⁻¹¹ m**。
ステップ終了時の幾何計測であり、連続非貫通の数学的保証ではない。

費用は変更前のバイナリ（commit `20cb86f9`）を保存して比較した。
反復上限200の12条件を固定し、ケースごとに前後の実行順を交互にした。
一つの論理CPUに固定、各側ウォームアップ1回・新規ワールドで5回計測。
各ケース中央値の等重み平均が30.149 / 24.143 ms。
ケース別の速度比は **1.048–1.451倍**で、全12条件の双方が品質ゲートを通過した。
測定はモデル生成・IPC・ECS同期・トレースを除いたrelease backendループのみ。
観測された差であり、統計的な信頼区間や全ワークロードへの保証ではない。

最初の一括解法は毎ステップ再分解して費用が増えるケースがあった。
最終実装は前回解を現在の相補性条件で検証して再利用し、その余分な分解を避ける。
再利用時も品質基準を緩めない。
