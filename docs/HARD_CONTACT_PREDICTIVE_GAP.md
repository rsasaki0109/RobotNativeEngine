# 非ゼロの初期隙間からの予測接触

前回、床に接した箱では候補距離0.1 mmで20 mmと同じ軌道を得た。
今回の落下では、この距離を一律に小さくすると接触を取りこぼすことが分かった。
バックエンドの既定距離20 mmは変更していない。

## 固定した実験

3 kg、一辺0.1 mの箱、摩擦係数0.5、COMへの水平外力17.658 N。
初期回転・鉛直速度は0、重力9.81 m/s²、床は固定。
初期隙間50 µm・0.5 mm・5 mm × 水平初速0・0.2 m/s × 候補距離0・0.1・20 mm
× 時間刻み2・0.25 msの36条件を50 msずつ実行した。
正則化0、反復上限200、ギャップバイアスは従来のまま。

診断用 `friction_threshold` exampleに末尾引数 `INITIAL_GAP_M` と
`INITIAL_SPEED_M_S` を追加した。省略時はいずれも0で、既存の実験を維持する。

## 結果

「遅れ」は、接触なしの半陰的Eulerで箱の底面が床を横切るステップから、
初めて法線インパルス総和が1e-10 N sを超えるまでのステップ数。
各行は隙間3条件×水平初速2条件の6試行。

| 刻み | 候補距離 | 1ステップ遅れた試行 | 最大めり込み |
| --- | ---: | ---: | ---: |
| 2 ms | 0 | 6/6 | 336.64 µm |
| 2 ms | 0.1 mm | 4/6 | 336.64 µm |
| 2 ms | 20 mm | 0/6 | 1.24e-5 µm |
| 0.25 ms | 0 | 6/6 | 61.96 µm |
| 0.25 ms | 0.1 mm | 0/6 | 1.11e-6 µm |
| 0.25 ms | 20 mm | 0/6 | 1.11e-6 µm |

2 ms刻み・初期隙間5 mmでは、自由落下の第16ステップに床を横切る。
候補距離20 mmはこのステップで正の隙間から支持力を出す。
0.1 mmでは第17ステップまで接触を採用できない。
初期隙間0.5 mmも同様に1ステップ遅れ、最大88.6 µmめり込む。
50 µmでは0.1 mmでも間に合う。

全36条件でECSから観測した最大回転速度は0だった。
この対称な箱の結果から、非対称接触や多段積みでも回転しないとは言えない。
ECS回転速度は姿勢差から再構成されるため、数学的な厳密ゼロの保証でもない。

## 接触が早すぎないか

半陰的Eulerの接触前の軌道は、ステップ番号nに対して:

- 底面高さ: `gap₀ − 9.81 dt² n(n+1)/2`
- 水平位置: `v₀ dt n + 5.886 dt² n(n+1)/2`
- 水平速度: `v₀ + 5.886 dt n`
- 鉛直速度: `−9.81 dt n`

最初の荷重が出る直前まで実測と照合した。最大位置誤差9.03e-17 m、
最大速度誤差5.62e-14 m/s。全36条件で、床を横切るステップより前に荷重は出なかった。
広い候補距離は、離れた箱を直ちに支持することを意味していない。
これは離散時間の接触タイミング検証であり、連続時間の衝突時刻に厳密一致する主張ではない。

## 品質とコストへの含意

候補距離を0.1 mmに縮めて0.25 ms刻みにすれば、今回の隙間ではめり込みを抑えられる。
ただし2 ms刻みの8倍のステップ数を要する。実時間の8倍を測定したわけではない。
既定の20 mmは今回2 ms刻みを維持できたが、候補が増えることによる計算負荷は未測定。
次に必要なのは、多数の近接物体で候補数と実時間を測り、接近速度に応じた候補距離で
品質を保ちながら不要な候補を減らせるかを確認すること。

今回MuJoCoの新規比較や、2秒の品質ゲート・コスト比較は実施していない。
予測バイアスそのものの有効・無効比較でもない。既存の予測接触に十分な候補距離が
必要なことを確認した実験として扱う。

```bash
cargo build --release -p rne_physics_native --example friction_threshold

  target/release/examples/friction_threshold /tmp/predictive-gap.json.xz

  target/release/examples/friction_threshold /tmp/predictive-gap.json.xz --verify
```

接触前の自由落下、集計値を検査し、全条件の新規再実行と生データを完全比較する。
