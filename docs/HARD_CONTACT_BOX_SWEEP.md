# 動く箱のペアを位置で絞り込む

前回は離れた箱の詳細判定を途中で打ち切った。今回は、その詳細判定へ渡す組そのものを
減らす。動くコライダーが64個以上のとき、箱の範囲をX座標順に並べて近傍を列挙し、
Y・Z方向にも範囲が重なる組だけを残す。ペアの順序は元のコライダー順へ戻す。

箱以外の形状と混在するペアは従来どおり列挙する。非有限の範囲やマージンも絞り込まない。
静的コライダーへの判定、衝突グループ、同一ロボットの除外、隣接リンクの除外、
重複接触の除去、ソルバーは既存の処理を使う。接触候補距離20 mmは維持する。

## 接触を取りこぼさないための範囲

箱の半寸法ベクトルの長さをrとする。面の分離軸判定を通過するペアでは、
中心間距離は `rₐ + √3 rᵦ + √3 margin` 以下となる。
両箱を入れ替えた式も成り立つので、両式の平均も上限となる。
したがって、各箱の中心を囲む軸平行の範囲を、各方向に

`(1 + √3)/2 × r + √3/2 × max(margin, 0)`

だけ広げれば、回転によらずこの条件を満たすペアは重なる。
さらに面選択の1e-9 m許容値と座標スケールに応じた浮動小数点誤差の余裕を加える。
これは箱にぴったり合わせたAABBより広い範囲であり、接触判定の代わりではない。

予測接触の20 mmを範囲に含める。速度からの到達予測や連続衝突判定を新たに導入した
ものではなく、従来の離散時間の候補を保つための絞り込み。

## 検証

- 寸法・回転・位置の異なる80箱、3種類のmarginで、総当たりの詳細判定が接触を返す
  全ペアが残ることを確認。候補の順序も昇順で重複なし。
- margin境界、大きな座標、離れた箱、未知形状、不正な範囲のフォールバックを検証。
- 1・16・64・128箱の落下を変更前後で実行し、全100ステップの状態ハッシュを照合。
- 既存の落下36条件も診断データまで比較する。この36条件は物体数が少ないため、
  絞り込みの有効性ではなく、従来経路の回帰確認になる。

## 計測

基準はPR #480のコミット `bd9177cd`。同じ `contact_crowd` exampleを使用し、
2 ms刻み、0.2秒、床から5 mm離れた3 kgの箱を0.15 m間隔で配置。
箱同士の接触がない条件である。CPUを1つに固定し、ウォームアップ後、変更前後の
順序を交互にした5試行の中央値を比較する。stepと毎ステップのECS書き戻しを含み、
初期化・監査用ハッシュ・JSON出力は含めない。

| 計測 | 箱数 | 変更前 ms/物理秒 | 変更後 ms/物理秒 | 時間短縮 |
| --- | ---: | ---: | ---: | ---: |
| A | 1 | 6.428 | 7.100 | -10.5% |
| A | 16 | 105.320 | 102.719 | 2.5% |
| A | 64 | 506.980 | 407.623 | 19.6% |
| A | 128 | 1523.876 | 1116.176 | 26.8% |
| B | 1 | 6.682 | 6.142 | 8.1% |
| B | 16 | 113.472 | 121.811 | -7.3% |
| B | 64 | 522.384 | 423.315 | 19.0% |
| B | 128 | 1406.573 | 940.903 | 33.1% |

最終版のビルド・テスト終了後に2組を順番に計測した。64箱で約19〜20%、
128箱で約27〜33%短縮。少数の箱では符号も変わり、改善を確認できない。
共用環境のばらつきがあり、信頼区間や他CPUでの再現性は未評価。

範囲が密集する場合は、走査・保存するペア数が最悪O(N²)となる。
候補リストの構築コストもあるため、64個未満ではこの処理を使わない。
X方向の範囲が広く重なる配置、箱以外が多い配置、接触が密集したロボット環境での
性能は未評価。MuJoCoとの速度比較でもない。

## 再現

```bash
cargo build --release -p rne_physics_native --example contact_crowd
python scripts/contact_benchmark/contact_crowd.py \
  /path/to/before-sweep /path/to/after-sweep /tmp/box-sweep.json
python scripts/contact_benchmark/contact_crowd.py \
  /path/to/before-sweep /path/to/after-sweep /tmp/box-sweep.json --verify
```
